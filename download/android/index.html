Install or update

  1. Download the APK from this page on your Android phone.
  2. Open the downloaded file. Android may ask you to allow installation from your browser or file manager. Review the source and permission request yourself.
  3. Install over an existing signed Vanishr release. Do not uninstall or clear app storage to update. Those actions delete local encryption keys and retained chats.
  4. Open Vanishr while the phone is unlocked and sign in or create an account. A release-signed APK cannot update a debug-signed installation.

Future update prompts appear at most once per day. You can also use My profile > Check for updates. Every update requires Android's installation approval; executable code is not silently replaced.

Your first verified conversation

  1. Share your username with the person you want to contact, and add their username.
  2. Compare the displayed safety numbers through an independent trusted channel, such as an in-person conversation. Do not rely on messages through this same relay for verification.
  3. Confirm the identity, then send a text or photo. Choose view once, one hour, six hours or 24 hours.

Your optional profile photo is only exchanged after both people add and independently verify one another. A shared name or photo is not a substitute for safety-number verification.

New registrations may also see the sole human admin, Vanishr / @vanishr. Only the official signed-app identity pin permits that onboarding conversation without a manual identity prompt. It does not verify other contacts or grant photo access. The admin sees new-registration profile metadata, not unrelated conversations.

New-user messages to the admin

Version 0.5.5 supports encrypted first messages even after the recipient's one-time key pool runs out. The admin must update in place and open Vanishr once to publish their offline fallback keys. New senders must also update. Automatic admin introductions still use the signed app's pinned identity; ordinary contacts still need independent verification.

Fallback keys have a fixed lifetime and do not extend disappearing messages. Missing or expired keys still require the receiving app to open and republish. The reported Motorola Edge 50 Pro / Android 16 black-screen issue is not confirmed fixed by this update.

Account deletion confirmation

Version 0.5.6 fixes fresh Google and password deletion confirmation being rejected for a small phone/server clock difference. It provides clear retry instructions and confirmation after deletion completes. Google accounts must still confirm with the same Google account; password accounts must enter the account password. Local account data is erased only after the server confirms deletion.

Automated ownership, recovery and picker-lifecycle tests passed using synthetic Google responses. Actual Google-provider deletion on the reported phone is not independently verified. Do not uninstall or clear app data as a recovery workaround.

Encrypted contacts backup

Version 0.5.7 adds an optional backup, off by default, of your independently verified contacts and the private nicknames you gave them. Turn it on in My profile > Backup & restore. The app creates a recovery key that only you hold, encrypts the backup on your phone with it, and uploads only the encrypted file. Vanishr cannot recover the key. Save it in a password manager or on paper; without it the backup cannot be opened. The key can be shown again from the same screen on the phone that created it.

The backup never contains messages, photos, private keys, sessions, passwords or sign-in tokens. On a new phone, sign in, choose Restore from backup and enter the key. A contact is restored only if its current identity is exactly the one you verified before; anything else must be verified again. The relay keeps one encrypted file per account for at most 90 days after the last upload and deletes it when you turn the backup off or delete the account.

Uploads run in a short Android foreground service (data sync) with a Cancel notification, and only while you use the app, at most once a day. This release needs the matching relay update, which is deployed before the APK is offered. Emulator and synthetic-relay tests passed; physical-phone and manufacturer background behavior and an independent security review remain unverified. See the privacy policy.

Admin chat status

Version 0.5.8 fixes the automatic chat between the official admin and each new account, which did not show Online, Typing or Last seen. It now behaves like any other direct chat: each side sees the other's status while that app is open, and the sharing list holds up to 128 contacts at a time, the open chat first. The admin and the new account must both update; nothing is shared until both apps list each other. No relay update is needed.

The automatic chat is still not an independently verified contact: it does not count for groups, private profile photos or the contact backup. The app keeps checking the official admin's identity against its built-in pin, and a changed identity, a block or removing the chat stops the sharing. Tested with synthetic accounts on an emulator and a PostgreSQL/Redis relay; physical phones are not yet verified. See the privacy policy.
